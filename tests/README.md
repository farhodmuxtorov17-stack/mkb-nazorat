```
node tests/malumot.test.js

node tests/sahifalar.test.js
node tests/server.test.js

node tests/tarjima.mjs                      # все страницы, роль Administrator
node tests/tarjima.mjs --rol="Obyekt menejeri"   # экраны и пустые состояния этой роли
node tests/tarjima.mjs --sahifa=panel.html  # выбранные страницы
node tests/olcham.mjs --kenglik=390,1440
```

Каждый набор печатает `[OK]` / `[XATO]` и итог `Yakun: o'tdi N, yiqildi M`.
При любом отказе код выхода — 1.

Все проверки идут на демонстрационных данных с фиксированной датой
21.09.2026 (`window.MKB_BUGUN`, для сервера — `MKB_BUGUN`). Локальный реестр
`mahalliy/` не читается: локальный режим проверяется на двух вымышленных
записях, которые тест подставляет вместо файла.

## `server.test.js`

Сервер поднимается в том же процессе на порту 8791. Проверяются вход,
истечение сессии (часы процесса сдвигаются на 9 часов), чтение, белый список
полей PATCH, отказ для неверной стоимости, неизвестного статуса и пути к

локальный реестр с чужого адреса. Созданная тестом запись удаляется из
хранилища после прогона.

## `tarjima.test.js`

Словарь и правила `tarjima.js` загружаются в песочнице вместе с блоками
перевода из `yadro/app.js`; браузер не нужен. `tarjimaQil` ищет по ключу весь
текстовый узел целиком, поэтому ключ вида `«Заголовок:»` переводит только
одиночную подпись, а сообщение, собранное в коде как `"Заголовок: " + значение`
(тост, возврат действия, текст ошибки, запись истории), требует отдельного
правила с `{}`. Набор проверяет две вещи: перечисленные сборные сообщения
переводятся целиком, вместе с заголовком; и у каждого ключа словаря,
оканчивающегося двоеточием и собираемого в коде таким способом, такое правило
есть. Для сообщений особой формы (даты, счётчики) в тесте задано настоящее
продолжение строки.

Ещё две проверки закрывают случаи, где правило переводило строку лишь частично. В списках объектов (аренда, лоты, предложения) строка собирается как «название · код · статус», и переводиться должны оба словарных члена, а код — оставаться как есть. Площадь пишется с разделителем тысяч и часто стоит внутри `[data-tarjimasiz]`, поэтому единица проверяется и правилом, и функцией `mkbBirlikTarjima`.

## `nashr.test.js`

Набор выпуска. Пять групп.

1. **Согласие до входа.** На `kirish.html` есть флажок и обе ссылки; отправка
   формы без согласия не открывает сессию; согласие пишется в учётную запись
   (`FOYDLAR.rozilik`), а не только в браузер, и привязано к редакции
   документов `HUJJAT_TAHRIR`; уже открытая сессия тоже проходит проверку;
   `oferta.html` и `maxfiylik.html` открываются без сессии, показывают ту же
   редакцию и возвращают на вход.
2. **Счётчики рельса.** Каждое слагаемое `yonSonlar()` — длина отфильтрованной
   коллекции, а не число в коде; названия коллекций существуют в `malumot*.js`;
   при нуле значок не рисуется, больше 99 сокращается; ни одна страница не
   пишет `class="yon-son"` руками.
3. **Возврат назад.** У каждой рабочей страницы есть шапка и строка заголовка,
   куда ядро ставит кнопку; `orqagaChiz()` вызывается в общей отрисовке; у всех
   страниц, кроме панелей ролей и центров разделов, в хлебных крошках есть
   ссылка на родителя; на страницах без сессии есть своя кнопка возврата;
   кнопка скрывается только при печати.
4. **Запрещённые слова.** Пять слов из договора (список собран в наборе из
   слогов, чтобы файл теста проходил собственную проверку) не встречаются в
   файлах приложения ни разу. Исключения перечислены в самом наборе и
   закреплены: одна директива протокола поисковых роботов в `robots.txt` и три
   записи словаря, которые обслуживают только презентацию. Если закреплённая
   запись исчезнет или появится новое вхождение, набор падает. Отдельно
   проверяется, что эти записи словаря не используются ни на одной странице
   приложения.
5. **Снимки и конфиденциальность.** `assets/namuna/MANBA.md` перечисляет каждый
   снимок с автором, лицензией и источником; число снимков в тексте совпадает с
   фактическим; у каждого есть эскиз, ни один файл не больше 250 КБ; по каждому
   снимку транспорта записано состояние госномера. Реальный реестр `mahalliy/`,
   хранилище `server/malumotlar/` и старая копия `v8/` не отслеживаются git;
   ни одна страница не обращается к `mahalliy/`, сервер закрывает его для
   внешнего адреса, а в демонстрационных данных нет записей реального реестра.

## `tarjima.mjs` и `olcham.mjs`

`tests/brauzer.mjs` поднимает временный статический сервер на `127.0.0.1`
(без `mahalliy/` и `server/`) и управляет Edge через протокол DevTools.
Путь к Edge меняется переменной `MKB_EDGE`.

Карточки (`obyekt*.html`, `ish`, `lot`, `shartnoma`, `hodisa`, `qurilma`,
`sud-majlis`, `baholash-hisobot`, `sugurta-polis`, `korik-akti`,
`arxiv-obyekt`) открываются с `?id=`. После входа `idlar()` берёт из
демонстрационных данных первую запись каждой коллекции в области видимости
роли (`KARTOCHKALAR` в `brauzer.mjs`). Без `id` страница ушла бы на
`xato-404.html`, и проверка прошла бы впустую.

- `tarjima.mjs` открывает каждую страницу с `mkb-til=ru` и ищет текст с
  латинскими буквами без перевода. Исключения: имена собственные и адреса из
  демонстрационных данных, номера документов, коды и торговые марки. Внутри
  элементов `data-tarjimasiz` (числа, коды, имена) проверяются две вещи.
  Единицы измерения помечаются `#birlik:`, их переводит функция
  `window.mkbBirlikTarjima` из `tarjima.js`. Строка, которая целиком или
  одной частью (разделители `: `, `·`, `—`, `|`) совпадает с ключом
  `MKB_LUGAT`, помечается `#tarjimasiz:`: у неё есть перевод, значит её нельзя
  прятать в `data-tarjimasiz`. Имена собственные из данных, коды и марки
  из этой проверки исключены.
- `olcham.mjs` на ширинах 390, 768, 1280 и 1440 px проверяет отсутствие
  горизонтальной прокрутки, высоту шапки до 72 px на экранах от 1024 px и
  видимость поиска таблицы на 390 px, а также ошибки скриптов.
